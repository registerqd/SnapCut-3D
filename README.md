## 💡 为什么需要 SnapCut 3D？

随着消费级 3D 打印机（如拓竹 A1 mini、P1S/X1C、创想 Ender 系列等）的大规模普及，越来越多玩家与创客想要打印**大型手办雕像、头盔面具、Cosplay 长刀长剑道具、收纳盒与电子外壳**。

但绝大多数人都被卡在同一个致命物理瓶颈上：

1. **成型体积受限**：入门爆款拓竹 A1 mini 仅有 **180×180×180mm**，主流主力机型也仅为 **256mm** 立方体。尺寸一旦超过 200~300mm，**100% 无法直接打印，必须切开**。
2. **切片软件自带切割太弱**：
   - 只能傻瓜式平面一切为二，无法打市售标准强磁沉头孔；
   - 缺乏防呆机制，切开后两面完全对称，打印出来极易**装反、拼歪、旋转扭曲**；
   - 复杂曲面布尔运算极易产生破面、非流形边和微小悬空。
3. **专业 3D 建模软件门槛劝退**：
   - Blender、Fusion 360、ZBrush 的布尔运算与对齐装配门槛极高，新手为了切一个零件要学数周软件操作。
4. **圈内当下的最大流量密码：【磁吸 / 榫卯快拆组装】**：
   - 玩过 3D 打印的都知道：**免胶水、咔哒一声磁吸吸合、模块化快拆**，在 MakerWorld、Printables、B 站和小红书上拥有极强的自传播力与装配爽感！

**SnapCut 3D 桌面端应用就是为此而生的专属利器**：拖入模型 → 选择打印机与磁铁/榫卯规格 → 30秒生成带公差沉头孔与防呆榫卯的分件 STL，并附带五金采购与装配指南 BOM。

## ✨ 核心特性

### 1. 🖥️ 原生跨平台桌面体验 (Electron)
- 沉浸式暗黑工业设计，窗口大小自由缩放，全离线可用；
- 深度集成系统原生文件选择对话框与原生保存路径对话框，告别网页下载目录混杂困扰；
- 支持同时作为轻量 Web 服务运行，双模架构随意切换。

### 2. 🎯 主流 3D 打印机成型仓实时比对
- 内置 **拓竹 A1 mini (180³)**、**P1S / X1C / A1 (256³)**、**创想 Ender-3 (220×220×250)**、**纵维立方 Kobra 系列** 等机型成型空间立方体。
- 自动识别长、宽、高各轴向是否超限，直观标红预警，并智能推荐下刀轴向。

### 3. ⚡ 毫秒级纯本地几何切削与截面重建
- 纯 JavaScript 解析几何算法，百毫秒内完成相交线段提取与闭合环（Polygon Loops）拼接。
- 基于轻量高效的 **Earcut 算法** 实现带孔洞平面的高质量约束 Delaunay 三角剖分，**不依赖任何重型第三方库或云端 GPU**，杜绝非流形破面。

### 4. 🧲 市售标准强磁沉头孔自动生成
- 预设市售最容易采购的钕铁硼强磁尺寸：
  - **φ6 × 3 mm**（圈内首选·手办道具黄金尺寸，吸力 ~0.8kg）
  - **φ5 × 2 mm**（超薄小件、轻量零件、关节活动件）
  - **φ8 × 2 mm**（扁平大吸力、重型底座首选）
  - **φ10 × 3 mm**（大宝剑/长刀切件、承重件首选）
- 自动提供 **单孔居中**、**双孔对称**、**四孔矩阵** 布局。
- **自带挤出公差补偿（Clearance）**：默认预留 +0.2mm 内径余量与 +0.3mm 胶水沉头深度，打印完毕后磁铁直接压入，免去打磨烦恼。

### 5. 🪵 D 型截面防呆榫卯定位
- 采用创新的 **D 型截面（单侧切平）** 定位榫：
  - Part A 自动生成预留公差的 Socket 凹槽；
  - Part B 自动生成精准匹配的 Pin 凸台；
  - 彻底从几何根源上消除旋转松动与 180° 反向误装。
- 凸台顶部集成 **1mm 45° 导向倒角**，拼合时自动滑入自锁。

### 6. 💥 3D 爆炸分离检视 & 一键平放热床
- 切割完成后，零件自动沿切面法向量双向爆开分离，直观透视内部孔槽深度与形状。
- **一键平放热床**：自动计算切面法向与热床的旋转四元数，将切面作为底面平铺在打印床上，**免去打孔悬空支撑**，且获得最大的第一层附着面积。

### 7. 📦 全套 STL 资产导出与 BOM 采购指南
- 支持分别独立保存 `PartA_切分件.stl` 和 `PartB_切分件.stl`（标准紧凑二进制 STL 格式）。
- 支持一键导出 **ZIP 完整交付包**：内含零件模型，以及由系统自动生成的《装配指南与五金采购清单_BOM.txt》，包含所需磁铁尺寸数量、极性标记提醒与推荐切片参数。

## 🚀 快速上手与运行

### 方式一：运行桌面客户端 (推荐)

```bash
# 1. 克隆代码
git clone https://github.com/registerqd/SnapCut-3D.git
cd SnapCut-3D

# 2. 安装依赖
npm install

# 3. 启动桌面客户端
npm start
```

### 方式二：打包为独立安装包 (Windows / macOS / Linux)

```bash
# 构建 Windows 安装程序 (.exe / nsis)
npm run dist:win

# 构建 macOS 安装镜像 (.dmg)
npm run dist:mac

# 构建 Linux 便携程序 (.AppImage)
npm run dist:linux
```
生成的安装包将存放在 `dist/` 目录下。

### 方式三：以轻量 Web 模式运行

```bash
npm run web
# 访问 http://localhost:3008
```

## 🛠️ 创客装配与切片打印指南

1. **磁极防反装测试（非常关键！）**：
   - 压入磁铁之前，**务必先用两颗磁铁互相吸附测试**；
   - 用细油性记号笔在互相吸合的接触面上各点一个标记点；
   - 确保安装时：A 件露出标记点，B 件朝内压入标记点（保证两件靠近时能**自动吸合**，而不是相斥！）。
2. **切片软件打印参数推荐**：
   - **摆放方向**：使用工具界面的「🛏️ 一键平放热床」，将切削截面作为底面贴紧热床，免去内部支撑并获得极佳粘结力；
   - **外壁圈数（Wall Loops）**：设置为 **3 ~ 4 圈**（>= 1.2mm），保证磁铁孔壁具有足够的挤压强度，防止压入时崩裂；
   - **填充率（Infill）**：推荐 **15% ~ 25% 陀螺线（Gyroid）** 或自适应立方体填充。
3. **磁铁固定**：
   - 工具已预留 +0.2mm 适度公差；如果打印机轻微欠挤出导致偏松，在孔底点涂一小滴 **401 瞬间强力胶** 即可永久牢固固定。
